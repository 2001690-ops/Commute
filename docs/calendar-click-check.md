# V4.5 달력 하단 클릭 보완 검증

- 원래 증상: 사용자가 달력 중간 아래에서 출근 예정/근무 예정 항목 클릭이 되지 않는다고 보고했습니다.
- 재현 범위: 독립 브라우저의 기존 화면에서는 동일 증상이 재현되지 않았습니다. 임베디드 화면/사용자 브라우저에서의 원인은 확정하지 않았습니다.
- 보완: 긴 달력의 세로 스크롤을 화면 높이 내로 제한하고 요일 헤더를 고정합니다. 편집창은 body 포털과 네이티브 dialog 최상위 레이어로 표시해 달력 overflow와 겹침으로 인한 영향을 피합니다. 닫기/배경 클릭/Esc와 포커스 복귀를 처리합니다.
- 테스트 데이터: 2026년 10월, 직원 8명, 매일 일정. 운영 데이터는 사용하거나 변경하지 않았습니다.
- 브라우저 확인: 1일·16일·31일의 마지막 직원 일정 버튼 클릭 시 정확한 날짜의 입력창이 열립니다. dialog는 viewport 높이 안에서 :modal 최상위 레이어에 있습니다.
- 31일의 출근 예정 글자를 직접 클릭해도 입력창이 열립니다. 31일 + 버튼도 정상입니다.
- Esc로 닫으면 dialog가 제거됩니다. 닫기 버튼으로도 정상적으로 제거됩니다.
- 이 검증은 사용자 Windows/ChatGPT 내 임베디드 화면에서 실제로 수정이 확인되었다는 뜻은 아닙니다.
